# Illustrating Paragraphs

図解画像には `$diagram-generation-rules` の基本規則を適用する。ほかに適用可能な図解用 Context も併用できる。

## 目的

Markdown の説明文を、各段落の第一文（トピックセンテンス）が伝える内容を一目で直感的に理解できる図解付きの文書にする。

## 成果

入力 Markdown の本文と順序を保ち、すべての散文段落の直後に、その段落専用の図解画像を Markdown 画像リンクとして挿入した Markdown が成果である。

成果物は次の状態を満たしている。

- 入力の各散文段落に対応する画像が一つずつ存在し、漏れや重複がない。
- 各画像リンクは、対応する段落との間に別の内容を挟まず、その直後にある。
- 各リンク先は、成果物から参照できる実在の画像ファイルである。
- 各画像のメインメッセージは、対応段落の第一文（トピックセンテンス）が伝える内容であり、画像だけを見ても大まかに理解できる。
- 第二文以降の内容は、第一文のメッセージを伝えるために必要な場合に限って図解に取り込まれている。後続の文に重要な内容があっても、それが画像のメインメッセージにはなっていない。
- 第2段落以降の各画像は、その段落とそれ以前の段落との意味上の関係が、画像だけから一目で伝わる形で表されている。
- 複数の画像に同じ概念が登場する場合、その概念を表す図・絵の見た目はすべて同じであり、ラベルが付いている場合はラベル名もすべて同じである。読者が画像をまたいで同じものだと認識できる。
- 異なる概念は、ラベルを隠しても図・絵の違いから識別できる。ラベル名だけを変えた同じ絵を、別の概念に使わない。
- 適用される図解用 Context の規則が、段落との対応関係を損なわずに各画像へ反映されている。

散文段落以外の見出し、箇条書き、表、コードブロック、画像だけのブロックは、図解対象の段落として数えない。

## アクティビティ

### 1. 計画

全文の散文段落を確認し、生成する画像の全体計画を作る。計画には次の二つを含める。

- **概念一覧**：図解全体に登場する概念をすべて挙げ、各概念のラベル名と、画像をまたいで共通に使う見た目の対応関係を記す。ラベルを表示しない概念は、その旨を記す。異なる概念には、共通の画風を保ちながら、それぞれ固有の形・絵・配置パターンを割り当てる。文字やラベルだけを絵の代わりにしない。
- **画像一覧**：生成予定の画像ごとに、次の2項目を一組として記す。
  - **伝えること**：その段落の第一文が伝える、画像のメインメッセージ。
  - **見た目**：画面内の各要素の位置と大きさ、要素間の接続や向き、構図、背景と概念一覧にない要素の色を画像ごとに具体的に記す。概念の共通の見た目は概念一覧を参照し、この画像で変える部分だけ記す。

画像一覧で概念一覧の概念に言及するときは、毎回、概念一覧と同じ概念名を半角の二重引用符 `""` で囲む。日本語のかぎ括弧 `「」` は使わない。画像一覧で引用した概念名は、すべて概念一覧にも同じ名前の独立した項目として載せる。概念一覧で定めた形・色・ラベルを画像一覧で繰り返す必要はない。見た目を変える場合は、その画像での変更点を概念名に添えて記す。

計画を提出する前に、各画像の「伝えること」「見た目」を確認し、「伝えること」と「見た目」に現れる概念名を概念一覧と一つずつ照合する。引用符のない概念名や、概念一覧にも画像一覧にも色の指定がない要素があれば計画を直す。概念一覧のラベルを隠して見比べ、異なる概念が同じ絵になっていれば固有の表現に直す。

画像一覧の記入例：

> **伝えること**：同じ `"変更要求"` でも、活動ごとに `"影響範囲"` は異なる。
>
> **見た目**：左上に `"変更要求"` を置く。中央に活動を示す五つのアイコンを横並びにし、そこから下半分に広がる `"コードベース"` へ青い矢印を伸ばす。矢印の先には、それぞれ位置と大きさが異なる `"影響範囲"` を描く。背景は白にする。

Plan mode では、この計画を提出して画像生成には進まない。それ以外のモードでは、計画を作ったあと、その計画に沿って画像を生成し、成果物の Markdown に挿入する。

### 2. 実行

Plan mode 以外では、計画した全画像を生成する。同じ概念には計画したラベル名と見た目を一貫して使い、各画像を対応する段落の直後に配置する。

## 連続性を表す例

以下は上記の成果条件を満たす方法の例であり、必須の表現方法ではない。

- 段落 B が段落 A の一部を詳しく説明する場合、A の図解の形を残し、その一部を吹き出しで指す、または拡大して、その中に B の内容を図解する。
- 段落 X、Y、Z が段落 A を支える三つの並列な理由である場合、X、Y、Z を同じレイアウトで図解し、並列の概念であることを示す。
