# Illustrating Paragraphs

## 目的

Markdown の各対象段落のトピックセンテンスが伝える内容を図解し、対応箇所に画像を組み込んだ文書を完成させる Process である。
適用される図解基準・視覚スタイル・内容上の Context とユーザーの指定を受け入れる。特定の Context Skill の存在や名前は前提にせず、複数の Context を併用できる。

## 対象と成果

入力は paragraph writing された Markdown である。成果は、図解計画、元の本文と順序を保って画像リンクを挿入した Markdown、およびリンク先の画像ファイルである。

### 対象範囲と対応

- 範囲の指定がなければ、すべての散文段落が図解対象である。見出し・箇条書き・表・コードブロック・画像だけのブロックは、ユーザーが明示的に含めた場合だけ対象である。
- まとめ方の指定がなければ、一つの対象箇所につき一つの図解が対応している。複数箇所を一図にまとめる指定は、その箇所だけに適用されている。
- 図解は原文と同じ順序で対応づけられ、対象箇所を参照できる。明示的に対象外とされた箇所も識別できる。
- 一段落の図解の主題は、その第一文であるトピックセンテンスが伝える内容である。第二文以降の内容は、その主題の理解に必要なものだけが反映されている。
- 複数段落をまとめた図解の主題は、各トピックセンテンスとそれらの意味上の関係を統合した内容である。対象に含まれた非散文ブロックは、文書内で担う内容と他の対象箇所との関係が反映されている。

### 図解計画

- 計画には、適用する図解基準とスタイルの指定、概念一覧、原文順の図解一覧が存在する。指定は実装時に特定でき、未指定部分について採用した表現も記されている。
- 各図解には、対象箇所・主題と、一つの ASCII 構図が記されている。
- 第2番目以降の図解には、先行する対象箇所との意味上の関係、および前後で継続・追加・変化・消失するモノ・コトが記されている。
- 計画は、適用される図解基準・スタイルと、対象範囲・主題・画像仕様に適合している。

### 画像と文書

- 計画された各図解に対応するラスター画像が一つずつあり、漏れや重複がない。各画像は、対応する計画と適用される図解基準・スタイルに適合している。
- 各画像のアスペクト比は正確に 16:9 であり、描画領域はフレームの外周まで使われ、外周の空白・余白・パディングは 0 である。
- 画像リンクは、挿入位置の指定があればその位置にあり、指定がなければ対象箇所の直後にある。複数箇所をまとめた図解は、指定がなければ最後の対象箇所の直後にある。
- 各リンク先は Markdown から参照できる実在の画像ファイルである。保存先とファイル名は、ユーザーの指定がある場合はその指定に一致している。
- 元の本文と順序が保持されている。

## 計画から実装へ

1. 適用される図解基準とスタイルを用い、概念一覧と各図解の ASCII 構図を計画する。
2. 計画の全図を適用される図解基準・スタイル・画像仕様と照合する。実際の寸法や接続を含む各基準を確認し、不一致を解消する。
3. 適合した計画に従って画像生成を行い、画像を保存して対応箇所にリンクを挿入する。

計画のみを求められた場合、または Plan mode では、実際の図解計画を提示して終了する。画像生成と文書編集は行わない。実装まで依頼されている場合は計画から実装まで進める。
既存の図解計画が入力された場合は再利用し、指定が変わった箇所に影響する計画を更新して実装する。
