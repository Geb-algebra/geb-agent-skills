# Illustrating Paragraphs

## 入力

段落との対応が記された図解計画、その計画に記録された図解方法、および参照元の Markdown を入力とする。別に作られた構図計画がある場合は、記録された図解方法に適合するものだけを入力として利用できる。

## 目的

計画された各 diagram を画像として生成し、対応する箇所へ挿入する。

## 成果

入力 Markdown の本文と順序を保ち、計画された全 diagram の画像リンクを対応箇所へ挿入した Markdown と、リンク先の画像ファイルが成果である。

成果物は次の状態を満たしている。

- 計画された各 diagram に対応する画像ファイルが一つずつ生成され、漏れや重複がない。
- 一つの対象箇所に対応する画像リンクは、ユーザーが挿入位置を指定していればその位置にあり、指定していなければその箇所の直後にある。複数の対象箇所に対応する画像リンクは、指定位置がなければ対応する最後の箇所の直後にある。
- 各リンク先は、成果物から参照できる実在の画像ファイルである。
- 各画像は、対応する diagram 計画と、計画に記録された図解方法に適合している。
- 各 diagram 計画に記された、概念一覧に含まれない局所的な概念や補助的な要素は、計画に記録された図解方法の範囲内で表現方法が決められている。計画に記されていない要素は追加されていない。

この Skill は、diagram 計画に記された概念一覧外の局所要素の表現方法を決める場合を除き、入力された内容計画や構図計画を作成または改訂しない。実行時に適用する図解方法を変更する必要がある場合は実行せず、その方法を使った図解計画の作成を求める。
