# Diagram Design Principles

## 適用範囲

説明用の図解およびその構図計画に適用する設計 Context である。活動の目的、成果、作業順序、評価手続き、画像生成、提出形式は定めない。

## 原則と不変条件

### 文字図形が主・絵は補足

- 単純図形、短いラベル、配置、矢印、包含などの関係表現が主題の意味を担っている。
- 主題を担う各図形には、それが表すモノ・コトを識別できる短いラベルがある。ラベルは複数語でもよいが、文章ではない。
- 絵・アイコンは、対応する図形の内側または直近で理解と識別を助ける補助であり、絵だけに概念や関係の意味を担わせていない。
- 説明用の短文は、図形内、接続線上、または対象へ接続されたコールアウトとして対象との対応を識別できる。
- 図解要素と対応しない説明文、見出し、キャプションは単独で存在していない。

### 正確性より直感的理解優先

- 主題を変質させない範囲で、厳密さや網羅性より直感的な理解を優先している。
- 主題の理解に不要な説明、細部、冗長な情報がない。
- 簡略化しても、トピックセンテンスが表す中心的な意味は欠落または逆転していない。
- 文字と図形は、中心的な意味を保てる範囲で少なく大きい。

### 概念を抽出し共通図解

共通概念は、重要な要素の一覧ではなく、図解内で反復する同じモノ・コトの共通表現である。反復は原文中の言及回数ではなく、計画対象となる全図解内の出現箇所で数える。一枚の図解内で複数回現れる場合も含む。

- 複数箇所に現れる同じモノ・コトがすべて共通概念であり、一箇所にしか現れない要素は重要度によらず共通概念ではない。
- 各共通概念には、一貫した名称、表示ラベル、基本図形、固有の絵またはアイコンがある。
- 異なる共通概念の絵・アイコンは重複していない。
- 各出現箇所の名称、ラベル、基本図形、絵またはアイコンは、その共通定義に適合している。
- 一箇所にしか現れない局所要素には、別表や個別の表現定義、絵またはアイコンを要求しない。構図内で名称により識別できればよい。
- 共通概念でない局所要素の絵・アイコンは、共通概念の絵・アイコンと重複していない。
- 反復する概念がなければ、共通概念は空であり、一覧を埋めるための要素を追加していない。

図解計画にこの Context が適用される場合は、さらに次の状態に適合する。

- 計画に、共通概念だけで構成された共通概念一覧がある。局所要素はこの一覧に含まれない。反復概念がない場合も、空の一覧として存在する。
- 一覧の各項目から、概念名、表示ラベル、基本図形、固有の絵またはアイコンを識別できる。
- ASCII 構図または自然文の構図説明では、登場する共通概念を一覧と同じ概念名で識別できる。
