# Planning Paragraph Illustrations

## Plan mode での実行

Plan mode では、この Skill を後で実行するための作業計画を作らず、この Skill 自体をその場で実行し、図解計画を Plan mode の成果として提示する。画像生成や Markdown への画像挿入には進まない。

## 入力条件

計画を始める時点で、使用する図解方法がユーザーのプロンプト、適用中の Skill、`AGENTS.md` などから明示的に特定できなければならない。図解方法とは、図解の生成・構図・視覚表現に適用する Context と明示指示の集合を指す。図解方法には、少なくとも利用可能な canvas の寸法または縦横比、文字量、正確性、イラストの複雑性を判断できる規則が含まれている必要がある。

図解方法が特定できない、または上記の判断に必要な規則が不足している場合は、図解計画を作らず、使用する図解方法をユーザーに聞く。

## 目的

paragraph writing された Markdown の説明文を、各対象箇所のトピックセンテンスが伝える内容を直感的に示す図解計画にする。

## 成果

入力 Markdown に対応する「採用する図解方法」「概念一覧」「原文と同じ順序の diagram 一覧」からなる図解計画が成果である。

### 採用する図解方法の不変条件

- 適用する Context と明示指示の出典が、実行時に同じ集合を特定できる形で記されている。

### 概念一覧の不変条件

- 図解対象となった複数の散文段落にわたって説明の主要要素として登場する概念だけが含まれている。図解対象外の段落での登場は数えず、図解対象の一つの段落だけに登場する概念や補助的な要素は含まれていない。
- 同じ概念に一つの名称が一貫して使われている。
- 各概念には、適用する図解方法に従ったラベル名と、diagram 間で共通に使う図解上の表現方法が記されている。ラベルを表示しない場合は、その旨が記されている。

### diagram 一覧の不変条件

- 各 diagram 計画には、その構図を表す ASCII 図が一つ存在する。
- 各 ASCII 図から、構成要素の位置、占有サイズ、および該当する向きや接続関係を判別できる。ASCII 図の寸法、縦横比、文字量、細かさは一律ではなく、採用する図解方法で利用可能な canvas、文字量、正確性、イラストの複雑性に適合している。
- 図解範囲についてユーザーから明示的な指示がない場合、入力のすべての散文段落が図解対象である。一部分だけの図解や図解しない段落をユーザーが明示した場合、対象範囲はその指示と一致している。
- 散文段落以外の見出し、箇条書き、表、コードブロック、画像だけのブロックは、ユーザーが明示的に対象へ含めない限り、既定の図解対象として数えない。
- diagram のまとめ方についてユーザーから明示的な指示がない対象箇所は、一箇所につき一つの diagram として計画されている。複数箇所を一つの diagram にまとめることをユーザーが明示した場合、その箇所だけを指定どおりにまとめ、まとめ方を指定されていない残りの対象箇所には一箇所一図の既定を適用する。
- 各 diagram 計画から、対応する一つ以上の対象箇所を参照できる。図解対象外とされた箇所は、対象外であることを計画から判別できる。
- 一段落に対応する diagram のメインメッセージは、その段落の第一文であるトピックセンテンスが伝える内容である。複数段落に対応する diagram のメインメッセージは、各段落のトピックセンテンスと、それらの意味上の関係を統合した内容である。ユーザーが非散文ブロックを明示的に対象へ含めた場合は、そのブロックが文書内で担う内容と、同じ diagram のほかの対象箇所との関係もメインメッセージに反映されている。
- 第二文以降の内容は、対応するトピックセンテンスのメッセージを伝えるために必要な場合に限って取り込まれ、diagram のメインメッセージにはなっていない。
- 各 diagram 計画には、その diagram に登場する概念一覧の概念が、概念一覧と同じ名称で記されている。
- 各 diagram 計画には、対応する全対象箇所から取り込む、概念一覧に含まれない局所的な概念と補助的な要素も記されている。ASCII 図ではそれらを名称付きプレースホルダーとして配置するが、最終的な形状、アイコン、色、画風は記されていない。実行時に、採用する図解方法の範囲内でその表現方法を決められる。
- 第2番目以降の各 diagram 計画には、対応箇所と先行する図解対象箇所との意味上の関係、および前後で継続、追加、変化、消失する概念が記されている。
- 各 diagram 計画は、採用する図解方法の範囲内で実行可能である。
- 適用される内容上の Context と図解方法が、対象箇所との対応、トピックセンテンス中心のメッセージ、diagram 間の意味上の連続性を損なわずに反映されている。

### 図解計画全体の不変条件

- 画像ファイルの生成と既存 Markdown への画像リンク挿入は実行されていない。
