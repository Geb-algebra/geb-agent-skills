# Minimal Flat Diagram Style

## 適用範囲

説明用の図解を作成、編集、またはレビューするとき、その視覚表現に以下の規則を適用する。活動の目的、成果物、作業手順、出力形式は、この Context では定めない。

## 不変条件

### 形と複雑性

- Web UI、SVG、PowerPoint の図のように、少ない色数と、はっきりした線、文字、塗りつぶしで表現されている。
- 要素数と各要素の複雑性は、伝える内容を識別できる最小限に抑えられている。
- 奥行きがなければ対象の構造や関係を伝えられない場合を除き、要素は二次元かつ平面的に表現されている。
- 人間は、丸い頭と直線的な胴体・四肢からなるピクトグラムとして表現されている。

### 色

図解に使われている色は、次の役割に対応する指定色だけである。

| 役割 | 色 |
|---|---|
| 通常の線・塗りつぶし | `#a2a2ad` |
| 通常の文字 | `#63676b` |
| アクセントの線・塗りつぶし | `#002538` |
| アクセント文字 | `#002538` |
| 背景 | `#fffff0` |

### 文字

- 意味を担う各図解要素には、それが何を表すかを示す1 phraseのラベルが付いている。 ラベルは複数単語あっても良いが、文章ではない。
- 説明のために追加される文字は、この1 phraseのラベルを基本として最小限である。文章は、1 phraseのラベルと図だけでは意味を伝えられない場合に限られている。
- UI、看板、コードなど、図解対象そのものに含まれる文字は、主題や対象を識別するために必要な部分が残されている。表示する文字の内容と言語は元の対象と一致している。
- 図解対象に元から含まれる文字を除き、追加する1 phraseのラベルと、どうしても必要な説明文は英語で書かれている。
- 日本語には Noto Sans JP、英語には Ubuntu、コードには Ubuntu Mono が使われている。
