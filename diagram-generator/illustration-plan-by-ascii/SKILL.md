# Illustration Plan by ASCII

図解の構図を ASCII で計画する場合は、ラフ・簡略な配置図・途中案にもこのスキルを適用する。「構図が伝われば十分」「図が多い」「簡略版だから」を理由に、適用や寸法条件を省略しない。

**ユーザーによる寸法指定がない場合、全図を内側 横32マス×縦18行（横:縦 = 16:9）に統一する。これは推奨値ではなく必須のデフォルトである。** 「簡潔に」「ラフで」という依頼は寸法変更の指定には当たらない。

## 目的

生成予定の図解ごとの構図を、要素の位置・大きさ・向き・接続関係が一目で分かる ASCII art として計画する。

## 成果

計画する各図解に、長方形の外枠で囲んだ ASCII art と、その直下の注釈を収めたコードブロックが一つずつ存在する。

成果物は次の状態を満たしている。ここで、単位「マス」は全角1文字、半角2文字を指す。

- ASCII art は長方形の外枠内だけに描かれ、コードブロックに入っている。
- 外枠と枠内の線は Unicode の罫線素片 `┌ ┐ └ ┘ ─ │ ├ ┤ ┬ ┴ ┼` を使い、隣接する線が切れ目なくつながって見える。角、分岐、交差には、その接続方向に合う罫線素片を使う。外枠を `+ - |` や `＋ － ｜` で代用しない。
- 矢印は `→↑↓←` を使用する。
- 外枠を含む全行の横マス数が等しい。罫線素片は半角文字として数え、半角文字は行ごとの合計が偶数である。
- 一つの計画に含まれるすべてのASCII図について、外枠の縦の行数と横のマス数がそれぞれ等しい。
- 縦横比は、外枠罫線を除く枠の内側のマス数の比で計測する。ユーザーが縦横比を指定した場合はその比率、指定しない場合は `16:9` に最も近い整数マスの縦横比になっている。
- ユーザーが横方向のマス数を指定した場合はその内側幅、指定しない場合は外枠を除く内側幅が32マスである。
- 枠内には構図だけがあり、色、強調、画風など構図以外の視覚指定は表現されていない。それらの指定は ASCII 外枠の下、かつコードブロックの終了フェンスより前に、注釈として書かれている。

比率の表記は横:縦とする。ユーザーが幅だけを指定した場合は比率16:9を、比率だけを指定した場合は内側幅32マスを維持する。整数の高さが一意に定まらない場合は、内側幅に対して最も近い整数の内側高さを使う。注釈は外枠寸法に含めない。

## 寸法の確定と検証

描画前に全図共通の内側幅と内側高さを確定する。未指定時の実寸は次のとおり。

| 対象 | 必須寸法 |
|---|---|
| 内側 | 横32マス（半角64文字分）×縦18行 |
| 上下の外枠 | 角の間に `─` が64個 |
| 外枠を含む各行 | 半角66文字分（33マス） |
| 外枠を含む高さ | 20行（上枠1行＋内側18行＋下枠1行） |

提出前に、生成した全図の実際の行幅・内側行数・罫線の接続を数えて検証する。代表図だけの確認や「32×18」と書いた注記だけでは検証にならない。空白行も内側行数に含め、要素が少ない図も余白で共通寸法を保つ。寸法不一致や接続不良があれば修正してから提出する。
