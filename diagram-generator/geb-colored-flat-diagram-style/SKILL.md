# Geb Colored Flat Diagram Style

## 適用範囲

説明用の図解を作成、編集、またはレビューするとき、配色、絵・アイコンの描画上の単純さ、書体に以下の規則を適用する。
情報の選択、図形とラベルによる意味表現、文字量、構図、活動の目的、成果物、作業手順、出力形式は対象外である。

## 不変条件

### 絵・アイコンの単純さ

- 絵・アイコンは、対象を識別できる最小限の線、面、細部だけで構成されている。
- 絵・アイコンは二次元かつ平面的であり、立体感、陰影、写実的な質感が使われていない。
- 人間は、丸い頭と直線的な胴体・四肢からなるピクトグラムとして表現されている。

### 色

図解に使われている色は、次の役割に対応する指定色だけである。

| 役割 | 色 |
|---|---|
| 通常の線・塗りつぶし | `#a2a2ad` |
| 通常の文字 | `#63676b` |
| アクセントの線・塗りつぶし | `#002538` |
| アクセント文字 | `#002538` |
| 背景 | `#fffff0` |

背景は透明にせず、背景色で塗りつぶす。

### 文字

- 図解対象に元から含まれる文字を除き、追加する1 phraseのラベルと、どうしても必要な説明文は英語で書かれている。
- 日本語には Noto Sans JP、英語には Ubuntu、コードには Ubuntu Mono が使われている。
