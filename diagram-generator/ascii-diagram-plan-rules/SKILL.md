# ASCII Diagram Plan Rules

## 適用範囲

図解やイラストの構図を ASCII art で表す計画に適用する Context である。ラフ、簡略な配置図、途中案、複数図の計画も対象に含む。
図解する内容、活動の目的、成果物、作業順序、画風、色は定めない。

「構図が伝われば十分」「簡潔なラフである」「図が多い」という理由で、以下の規則への適合を省略しない。

## 不変条件

ここで1マスは全角1文字、半角2文字、または絵文字1 grapheme clusterに相当する。絵文字の grapheme cluster を構成する個々の code point は、全角・半角文字として重ねて数えない。縦横比は横:縦で表し、外枠罫線を除く内側のマス数で計測する。

### 外枠と記号

- 計画する各図解にはコードブロックが一つずつあり、その中に長方形の外枠で囲まれた ASCII art と、外枠直下の注釈が一組だけ収められている。
- ASCII art は長方形の外枠内だけに描かれている。
- 外枠と枠内の線には Unicode の罫線素片 `┌ ┐ └ ┘ ─ │ ├ ┤ ┬ ┴ ┼` が使われている。外枠は `+ - |` や `＋ － ｜` で代用されていない。
- 隣接する線は切れ目なくつながって見え、角・分岐・交差には接続方向に合う罫線素片が使われている。
- 矢印には `→ ↑ ↓ ←` が使われている。
- 外枠を含む全行の横マス数が等しい。罫線素片は半角1文字として数えられ、各行に含まれる半角文字の合計は偶数である。

### 寸法

- 各 ASCII art を描く時点で、一つの計画に共通する内側幅と内側高さが確定している。
- ユーザーによる寸法指定がない場合、すべての ASCII art の内側は横32マス×縦18行であり、縦横比は16:9である。
- ユーザーが縦横比を指定した場合はその比率が使われている。横方向のマス数も指定されている場合は、その内側幅に対して指定比率に最も近い整数の内側高さが使われている。
- ユーザーが横方向のマス数を指定した場合はその内側幅が使われ、比率の指定がなければ16:9が維持されている。
- ユーザーが比率だけを指定した場合は、内側幅32マスが維持されている。
- 内側幅に対して整数の高さが一意に定まらない場合、指定された比率に最も近い整数の内側高さが使われている。
- 一つの計画に含まれるすべての ASCII art は、外枠の横マス数と縦の行数がそれぞれ等しい。要素が少ない図も空白で共通寸法が保たれている。

寸法指定がない場合の実寸は次の状態である。

| 対象 | 寸法 |
|---|---|
| 内側 | 横32マス（半角64文字分）×縦18行 |
| 上下の外枠 | 角の間に `─` が64個 |
| 外枠を含む各行 | 半角66文字分（33マス） |
| 外枠を含む高さ | 20行（上枠1行＋内側18行＋下枠1行） |

### 構図と注釈

- ASCII art から、要素の位置・大きさ・向き・該当する接続関係を判別できる。
- 枠内には構図だけがあり、色・強調・画風など構図以外の視覚指定は表現されていない。
- 構図以外の視覚指定がある場合、その指定は ASCII 外枠の直下かつコードブロックの終了フェンスより前に、注釈として記されている。
- 注釈は ASCII art の寸法に含まれていない。

### 検証可能性

- 適合判定では、すべての ASCII art の実際の行幅・内側行数・半角文字数・縦横比・罫線の接続が数えられている。代表図だけの実測では適合と判定されていない。
- 空白行も内側行数に含まれている。
- 「32×18」などの寸法注記は実測の代わりに使われず、実際に描かれた各図が指定寸法に一致している。
