# ASCII Diagram Plan Rules

## 適用範囲

図解やイラストの構図を ASCII art で表す計画に適用する Context である。ラフ、簡略な配置図、途中案、複数図の計画も対象に含む。
図解する内容、活動の目的、成果物、作業順序、画風、色は定めない。

「構図が伝われば十分」「簡潔なラフである」「図が多い」という理由で、以下の規則への適合を省略しない。

## 不変条件

ここで1マスは全角1文字、半角2文字、または絵文字1 grapheme clusterに相当する。絵文字の grapheme cluster を構成する個々の code point は、全角・半角文字として重ねて数えない。アスペクト比とマス数比は横:縦で表し、マス数比は外枠罫線を除く内側のマス数で計測する。

横書きでは横方向の1マスが縦方向の1行より多くの情報を保持するため、指定されたアスペクト比をマス数比へ直接使用しない。指定アスペクト比を `横:縦 = W:H` としたとき、ASCII art の内側に適用するマス数比は `1.5W:H` とする。たとえば、アスペクト比16:9に対応するマス数比は24:9である。

### 外枠と記号

- 計画する各図解にはコードブロックが一つずつあり、その中に長方形の外枠で囲まれた ASCII art と、外枠直下の注釈が一組だけ収められている。
- ASCII art は長方形の外枠内だけに描かれている。
- 外枠と枠内の線には Unicode の罫線素片 `┌ ┐ └ ┘ ─ │ ├ ┤ ┬ ┴ ┼` が使われている。外枠は `+ - |` や `＋ － ｜` で代用されていない。
- 隣接する線は切れ目なくつながって見え、角・分岐・交差には接続方向に合う罫線素片が使われている。
- 矢印には `→ ↑ ↓ ←` が使われている。
- 外枠を含む全行の横マス数が等しい。罫線素片は半角1文字として数えられ、各行に含まれる半角文字の合計は偶数である。

### 寸法

- 一つの計画に含まれるすべての ASCII art には、共通の内側幅と内側高さが使われている。要素が少ない図も空白で共通寸法が保たれている。
- アスペクト比の指定がない場合は16:9が使われ、そのマス数比は24:9である。ユーザーがアスペクト比を指定した場合はその指定が使われ、横だけを1.5倍したマス数比へ変換されている。
- ユーザーが内側幅または内側高さを明示した場合はその寸法が使われ、指定されていない側は補正後のマス数比に最も近い整数になる。理想値がちょうど二つの整数の中間になる場合は、大きい方の整数へ丸める。
- ユーザーが幅と高さを指定していない場合、共通寸法は、計画内のすべての構図が適用される第三者の理解可能性評価に合格できる範囲で最小である。同じ補正後のマス数比を保って幅と高さをさらに小さくすると、少なくとも一つの構図が第三者評価に不合格となるか、必要な要素・文字・接続を判別可能に配置できなくなる。
- 個々の構図ごとに寸法を縮小せず、最も大きな寸法を必要とする構図に合わせた共通寸法が計画全体で使われている。

### 構図と注釈

- ASCII art から、要素の位置・大きさ・向き・該当する接続関係を判別できる。
- 枠内には構図だけがあり、色・強調・画風など構図以外の視覚指定は表現されていない。
- 構図以外の視覚指定がある場合、その指定は ASCII 外枠の直下かつコードブロックの終了フェンスより前に、注釈として記されている。
- 注釈は ASCII art の寸法に含まれていない。

### 検証可能性

- 適合判定では、すべての ASCII art の実際の行幅・内側行数・半角文字数・補正後のマス数比・罫線の接続が数えられている。代表図だけの実測では適合と判定されていない。
- 空白行も内側行数に含まれている。
- 寸法注記は実測の代わりに使われず、実際に描かれた各図が計画共通の寸法に一致している。
