# EPUB 翻訳

翻訳を章ごとに委任し、コンテキスト使用量とコストを抑える。成果物は原書順の翻訳と確定用語集。指定がなければ章別 Markdown で保存する。

1. 目次と読書順を照合して指定範囲を章ごとのファイルに取り出す。章境界には目次リンクのフラグメントも反映する。長い章は節などで分け、処理後に元の順序で戻す。
2. 親のモデルにかかわらず、章や分割片ごとに独立したサブエージェントを起動する。利用可能な Luna または Haiku を明示し、effort は `high`、親の会話履歴は継承しない。この組み合わせを使えない場合は、使えない設定を報告して翻訳を保留する。
3. 親が用語集を管理する。指定訳や参照できる既存訳・原書の用語集で初期化し、原語・確定訳・適用する意味と、判明している別表記や定義位置を記録する。並行実行では同じ版から各章に必要な項目を選び、対象原文、訳先言語、出力先とともに渡す。担当は該当する意味で確定訳を使い、訳文を直接保存する。親への返却は保存先と、新出の専門用語・定義語の候補（原語・仮訳・意味・原文位置）に絞る。
4. 親が候補を集約し、同綴りの別義を分け、略語や別表記を同じ概念に紐づけて確定する。追加・変更した用語は、別表記も検索して定義より前の用例を含む対象箇所を特定する。原文の意味を照合し、確定訳との差分だけを手順 2 の設定で修正する。
5. 対象章の過不足と順序、同じ意味での確定訳の一致、見出し・注・参照の保持を確認し、翻訳と用語集を渡す。
