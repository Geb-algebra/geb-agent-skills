# OOUI implementation

## オブジェクトの視覚的同一性

- 同じオブジェクトの配色、形状、配置、振る舞い、などは、画面や場所を問わず同じにする。 理由がない限り、一つのコンポーネントとして実装し、それをアプリ全体を通して使用する。
- 画面上のオブジェクトに直接触れて操作しているような感覚を与える。可能な限り、オブジェクトの操作をオブジェクト外のボタン・コマンドではなく、ドラッグ&ドロップ・オブジェクト自体のクリックで行う。可能な限り、オブジェクト属性の編集をダイアログで行わず、属性のin-place編集 で行う。
- 身体的な動作に追従してリアルタイムに表示を更新する（フィードバック）。
- 逆の操作をすることで前の状態に戻せるようにする（可逆性）。
