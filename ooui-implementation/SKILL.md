# OOUI implementation

## オブジェクトの視覚的同一性

- 同じオブジェクトの配色、形状、配置、振る舞い、などは、画面や場所を問わず同じにする。 理由がない限り、一つのコンポーネントとして実装し、それをアプリ全体を通して使用する。
- 画面上のオブジェクトに直接触れて操作しているような感覚を与える。オブジェクトの操作を別のボタン・コマンド・ダイアログで行うより、ドラッグ&ドロップ・オブジェクト自体のクリック・属性のin-place編集 で実装することを優先する。
- 身体的な動作に追従してリアルタイムに表示を更新する（フィードバック）。
- 逆の操作をすることで前の状態に戻せるようにする（可逆性）。
